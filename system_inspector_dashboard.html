💻 PowerShell Diagnostic Command Snippet

Run this command in PowerShell to inspect live process port bindings anytime:

Get-NetTCPConnection -State Listen | ForEach-Object {
  $p = Get-Process -Id $_.OwningProcess -EA 0
  [PSCustomObject]@{
    Port = $_.LocalPort;
    PID = $_.OwningProcess;
    Name = $p.ProcessName
  }
} | Sort-Object Port | Out-GridView
